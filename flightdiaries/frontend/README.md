# Flight diaries: frontend

Ejercicios 9.19 a 9.22 de Full Stack Open (parte 9): frontend en React y TypeScript para el backend de `flightdiaries/backend`.

- Lista las entradas del diario y permite añadir nuevas.
- La fecha se elige con un campo de fecha, y el tiempo y la visibilidad con botones de opción.
- Si el backend rechaza una entrada, se muestra el motivo.

El servidor de desarrollo de Vite redirige `/api` al backend en `http://localhost:3000`.

```
cd ../backend && npm install --legacy-peer-deps && npm start
cd ../frontend && npm install && npm run dev
```
