# Full Stack Open, parte 9: TypeScript

Ejercicios de la parte 9 del curso [Full Stack Open](https://fullstackopen.com/) de la Universidad de Helsinki.

| Carpeta | Ejercicios | Contenido |
| --- | --- | --- |
| `healthapp` | 9.1–9.8 | Calculadoras de IMC y de ejercicio en TypeScript, por línea de comandos y como API con Express |
| `patientor/backend` | 9.9–9.16, 9.23, 9.25, 9.29 | Backend de Patientor con Express, tipos, validación con Zod y entradas del historial médico |
| `course` | 9.17–9.18 | App de React con TypeScript, uniones discriminadas y comprobación exhaustiva |
| `flightdiaries/frontend` | 9.19–9.22 | Frontend de React con TypeScript para el diario de vuelos |
| `patientor/frontend` | 9.24, 9.26–9.28, 9.30–9.33 | Página de cada paciente, historial con diagnósticos y formulario de nuevas entradas |

Las pruebas de `healthapp-tests`, `patientor-api-tests` y `patientor-tests` se ejecutan en GitHub Actions en cada push.
